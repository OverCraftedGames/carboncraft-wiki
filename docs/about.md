# About

CarbonCraft is run by **OverCrafted Games**, a small independent game studio. More about
us on [ocgames.xyz](https://ocgames.xyz).

## Our servers

| Server | What it is | Address |
|---|---|---|
| **CarbonCraft** | Hard-difficulty survival with a player-run economy, custom enchants, skills and factions | `play.carboncraft.xyz` (Java and Bedrock) |

## One membership

Carbon+ is our network membership: buy it once on the
[store](https://store.carboncraft.xyz) and it works on every OverCrafted Games server. Each
server has its own perks. Carbon+ bought in game with
[CarbonCoins](getting-started/money.md#carboncoins) (`/coinshop`) works on CarbonCraft only.
