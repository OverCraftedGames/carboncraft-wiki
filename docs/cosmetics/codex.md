# Collector's Codex

The Codex is your record of every collectible you've gathered. Type `/codex` (or
`/collection`) to open it.

It tracks four collections:

| Collection | What counts |
|---|---|
| **Heirlooms** | Every Heirloom item set |
| **The Syndicate** | The gear from each [faction shop](../syndicates/index.md) |
| **Plushies** | Each [plushie](plushies.md) set and pack |
| **Tags** | Every [tag](tags.md) you own |

Each collection is split into sets, and the Codex shows how many of each set you have.

## Registering items

Hold the items you want to record and type `/codex register`. Every new collectible in
your inventory is added at once.

- **You keep the item.** Registering doesn't take it away.
- **That copy is stamped** with your name ("In your Codex"), so nobody else can
  register it, even if you trade or sell it. Check before you buy second-hand.
- Tags count automatically as soon as you own them. There's nothing to register.

To check a single item, hold it and type `/codex check`. It tells you whether it's a
collectible, whether it's in your Codex, or whose Codex it's already in.

## Completing a set

When you register the last item in a set, the whole server is told you finished it.

For tags, the Codex also shows how to get each one, which makes it a handy checklist.
