# Commands

## Menus

| Command | Opens |
|---|---|
| `/help` | The main help menu, with every feature (also `/guide`) |
| `/rtp` | Random teleport into the Overworld, Nether, End or Legacy World |
| `/quests` | Daily, monthly and story quests, plus daily login rewards (also `/daily`) |
| `/wallet` | Your balance, CarbonCoins, vote points and crate keys |
| `/voting` | Vote tiers and your progress (also `/ranks`) |
| `/voteshop` | Spend vote points |
| `/coinshop` | Spend CarbonCoins on [tags](../cosmetics/tags.md), [plushies](../cosmetics/plushies.md), keys and more |
| `/tags` | Pick the [tag](../cosmetics/tags.md) shown next to your name |
| `/refer` | Friends you've [invited](inviting-friends.md) and their progress (also `/referrals`) |
| `/exchange` | Spend dollars on flex tags, Entropy or Zeta (also `/sink`) |
| `/enchants` | Browse every custom enchant |
| `/heirlooms` | Heirloom item sets |
| `/shophelp` | How to set up a chest shop |
| `/rules` | Server rules |
| `/syndicate` | Your standing with each [Syndicate faction](../syndicates/index.md) (also `/standing`) |

## Getting around

| Command | Does |
|---|---|
| `/spawn` | Back to spawn |
| `/sethome [name]` | Set a home where you're standing |
| `/home [name]` | Teleport to a home |
| `/crates` | Warp to the crates |
| `/leaderboards` | Warp to the leaderboards |
| `/pw` | Browse player warps |

## Land

| Command | Does |
|---|---|
| `/claimslist` | Your claims and claim blocks |
| `/trust <player>` | Let someone build in your claim |
| `/untrust <player>` | Take that back |
| `/abandonclaim` | Delete the claim you're standing in |

More in [Claiming land](claiming-land.md).

## Storage and items

| Command | Does |
|---|---|
| `/bp` | Your backpack |
| `/wb` | Portable crafting table |
| `/heads` | Decorative head catalogue |

## Mining, fishing and skills

| Command | Opens |
|---|---|
| `/skills` | Your [skills](../skills/index.md), levels and stats |
| `/mine menu` | The [mining](../activities/mining.md) menu (`/mine journal` for the in-game guide) |
| `/fish menu` | The [fishing](../activities/fishing.md) menu, or shift-click with a fishing rod |

## Voting and minigames

| Command | Does |
|---|---|
| `/vote` | Voting site links |
| `/zombies` | Join a Zombies arena |
| `/megaproject` | The current server-wide project board |

## Chat and community

| Command | Does |
|---|---|
| `/msg <player> <message>` | Private message |
| `/r <message>` | Reply to the last private message |
| `/discord` | Discord invite |
| `/store` | Store link |
| `/staffapp` | How to apply for staff |
